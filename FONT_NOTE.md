# Font note

The portrait uses a 0.600em monospace advance width. JetBrains Mono, DejaVu Sans Mono, Liberation Mono and Noto Sans Mono work with the geometry. Consolas is narrower, so embedding a JetBrains Mono subset is recommended if exact alignment matters.

JetBrains Mono is licensed under SIL OFL 1.1. If you embed a subset, commit the corresponding OFL license file.
